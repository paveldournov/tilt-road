Connect your iPhone and computer to the same home network. Open this page in Safari. No cloud account or app is needed.

1. Install the local certificate

iPhone motion access requires HTTPS. This profile contains only a development certificate—not device management or a VPN.

Download certificate profile

Tap Allow. Then open Settings → General → VPN & Device Management → RoadTilt Local Controller → Install.

2. Enable certificate trust

Open Settings → General → About → Certificate Trust Settings. Enable full trust for RoadTilt Local Controller.

Only trust the certificate from your own computer. It allows that computer’s local CA to issue trusted certificates. Keep its private key private, and remove this profile when you’re done testing.

3. Pair and fly

In the computer game, click Connect iPhone. Open the controller below and enter the two-digit pairing code. Enable motion, hold still to calibrate, and tap Start.

Can’t connect?

Use the same Wi-Fi/LAN, not cellular or an isolated guest network. If Windows asks, allow Node.js on your Private network only. The server uses TCP ports 8786 and 8787. Don’t open router ports or expose this server to the internet.

To remove trust later: Settings → General → VPN & Device Management → RoadTilt Local Controller → Remove Profile.
